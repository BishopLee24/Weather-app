My Weather App 🌦️

This is my responsive weather application built using HTML, CSS, and JavaScript that allows users to search for current weather conditions and a 5-day forecast for cities around the world.
This is my first project :)

---

GitHub Repository

[Weather App Repository](https://github.com/BishopLee24/Weather-app)

---

Features 🚀

- Current weather search
- 5-day weather forecast
- Dark mode toggle
- Temperature unit toggle (°C / °F)
- Search history with active highlighting
- Favorite cities system
- Local storage persistence
- Responsive mobile-friendly layout
- Dynamic weather icons
- Loading spinner animations
- Error handling for invalid cities
